# CINEMA PLUS

مشروع Full-stack عربي لكتالوج أفلام ومسلسلات، مع حسابات مستخدمين ولوحة إدارة ومفضلة وسجل مشاهدة.

## المتطلبات
- Node.js 20 أو أحدث
- npm

## التشغيل محليًا
1. فك ضغط المشروع.
2. افتح مجلد المشروع في VS Code.
3. انسخ `.env.example` إلى ملف باسم `.env`.
4. غيّر `JWT_SECRET` إلى قيمة عشوائية طويلة (32 حرفًا على الأقل)، وحدد بريد وكلمة مرور المدير.
5. نفّذ:
   ```bash
   npm install
   npm start
   ```
6. افتح `http://localhost:3000`.

## لوحة الإدارة
- سجّل الدخول باستخدام `ADMIN_EMAIL` و`ADMIN_PASSWORD` المحددين في `.env`.
- اضغط اسم حساب المدير في الشريط العلوي لفتح لوحة التحكم.
- أضف بيانات العمل وصورة البوستر وروابط المشاهدة/التحميل المصرح بها.
- يستطيع المدير تعديل وحذف المحتوى.

## الوظائف
- تصميم RTL عربي ومتجاوب.
- البحث والتصنيف والفرز.
- أفلام ومسلسلات.
- تسجيل حساب وتسجيل دخول.
- المفضلة وسجل المشاهدة.
- CRUD للمحتوى عبر لوحة المدير.
- SQLite محلية في `data/cinema.sqlite`.

## ملاحظات مهمة قبل النشر
- أضف فقط أعمالًا تملك حقوق نشرها أو لديك إذن بعرضها، واستخدم روابط منصات مرخصة. المشروع لا يتضمن أفلامًا محمية أو روابط قرصنة.
- استخدم HTTPS، وقيمة JWT سرية قوية، وكلمات مرور فريدة.
- غيّر إعدادات النسخ الاحتياطي لقاعدة البيانات، وأضف سياسة خصوصية وشروط استخدام ووسيلة تواصل.
- في الإنتاج يُفضّل تخزين الصور في خدمة تخزين ملفات، وتفعيل حماية إضافية ومراقبة محاولات الدخول.
- لا ترفع ملف `.env` أو مجلد `data` إلى مستودع عام.
